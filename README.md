## Neovim Setup

#### I will be updating both of my configuration time to time

## Steps to have your own dynamic Neovim Setup

- from dynamic i mean using both packer and lazy config on whim  
- clone this repo  
- rename the repo folder to `nvim` from `my-nvim-config`  
- replace this folder with your existing `nvim` folder  
- you are good to go, just use `git switch packer` or `git switch lazy` whenever you want to have access to both the configs :)

---

## Pros and Cons of both the Setup

### Packer

**Pros**
- build from scratch, you are in control  
- minimalistic & faster  

**Cons**
- lacks features or might require time to configure  

### Lazy

**Pros**
- comes with developer friendly tools out of the box  
- has lazy reloading for faster workflow  

**Cons**
- might feel a bit opinionated as many things come pre-built  
- can come across as bloated or overkill for simple development
